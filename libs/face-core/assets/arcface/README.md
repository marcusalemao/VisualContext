# w600k_mbf.onnx

MobileFaceNet trained with ArcFace on WebFace600K, from the InsightFace `buffalo_s` package
(https://github.com/deepinsight/insightface, release v0.7).

The code of InsightFace is MIT, **the pretrained model is not licensed for commercial use**
(https://www.insightface.ai/solutions/face-recognition-licensing). Used here for testing and for a
non-commercial academic demo only. Before any paid release: license it, or switch to the
face-api.js engine (MIT code, public-domain dlib weights).
