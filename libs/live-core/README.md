# live-core

Gemini Live protocol (`LiveProtocol`), HUD transcript (`Transcript`) and the WebSocket client (`LiveSession`, OkHttp).
Shared by `android/solo` (on the glasses) and `android/live` (Nexus plugin on the phone) through `kotlin.srcDir`.
